# Netflix Titles — Exploratory Data Analysis

EDA on the Netflix titles dataset (movies + TV shows) using pandas, matplotlib, and seaborn.

## Contents
- `Netflix.ipynb` — main analysis notebook
- `netflix_titles.csv` — dataset (movies & TV shows on Netflix)
- Output charts: `movies_vs_tvshows.png`, `top_10_countries.png`, `content_ratings.png`, `top_genres.png`, `content_growth.png`, `top_directors.png`

## Analysis covered
- Movies vs TV Shows split
- Top 10 countries producing content
- Content ratings distribution (TV-MA, TV-14, R, etc.)
- Top 10 genres
- Content growth by release year
- Top 10 directors by number of titles

## Tech stack
Python, pandas, matplotlib, seaborn

## Setup
```bash
pip install -r requirements.txt
jupyter notebook Netflix.ipynb
```
